# HanJoo IR 0.6.28 — JSON editing, import/export audit

The panel now supports editing a portable profile JSON directly or loading an edited JSON file into the editor. Library cards expose “Sửa JSON”; device management exposes “Sửa / nhập JSON”. Saving a profile preserves its profile ID and updates only the library. Saving device JSON replaces the selected device's control data while preserving its device ID and transmitter/receiver routing. Existing command IDs retain their entity IDs; removed command buttons are cleaned from the registry and new buttons/capabilities load through an awaited integration reload. Type changes require creating a new device. Dynamic protocol-engine metadata is retained: remove that block explicitly to switch a climate profile to learned RAW states.

Ordinary file import remains additive and creates new profiles. Devices previously created from profiles hold copies, so library edits do not silently overwrite their learned commands. Use the device editor to apply changed JSON to an existing device. JSON export is a portable control profile, not a complete HA backup of entity state, timers and hardware routing. Library export includes library profiles; export manually learned devices individually.

Import and edit validate before persistence, restore old data on write failure, support empty library round trips, reject duplicate JSON keys/nonfinite numbers/bad code containers/bad repeats and ambiguous duplicate climate states, and reconcile climate capability lists with imported cells. Fan speed enumeration includes newly added speeds beyond the predeclared list. The editor preserves drafts after errors, isolates stale file reads, blocks saving while reading, and skips language translation inside JSON textareas. File imports now expose failure reasons and correctly count empty libraries.

Validation: 14 JSON regressions, 13 learning/replay regressions, existing climate/timer regressions, and Node checks for stale learning sessions and JSON editor targets/error handling/file-read ordering. Checks use production parsers and methods with mocked HA storage/transport/registry; full HA frontend rendering and physical IR compatibility require a real HA installation. No claim of universal hardware compatibility or zero possible bugs.

Home Assistant add-on release notes are supplied in `hanjoo_ir_core/CHANGELOG.md`, alongside version 0.6.28 in config.yaml. Start/update the add-on and restart Home Assistant to load the new bundled Python integration, then refresh the browser panel.
